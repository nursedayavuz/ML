# Machine Learning Portfolio: Laboratory Applications & Rapid Prototyping

This repository contains various machine learning projects developed as part of the **"Introduction to Artificial Intelligence and Machine Learning"** course laboratory sessions at Bursa Technical University.

## 🎯 Project Objectives
The primary goal of these studies was to translate theoretical course knowledge into practical laboratory applications. The focus was on:
- Extracting insights from datasets quickly and accurately.
- Implementing core algorithms (KNN, Logistic Regression, K-Means) on laboratory scenarios.
- Utilizing AI-assisted development tools (Prompt Engineering) to optimize coding and performance reporting workflows.

## 🛠️ Tech Stack
- **Language:** Python 3.13
- **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
- **Environment:** VS Code & Laboratory Sessions

## 📂 Laboratory Projects List

| File Name | Project Subject | Key Algorithms |
| :--- | :--- | :--- |
| `penguin_classification_knn.py` | Penguin Species Classification | KNN (Manual Metrics) |
| `country_segmentation_kmeans.py` | Socio-Economic Country Analysis | K-Means, t-SNE |
| `breast_cancer_model_comparison.py` | Breast Cancer Diagnostic Models | Log. Reg. vs KNN |
| `customer_segmentation_kmeans.py` | Customer Behavior Profiling | K-Means, PCA |
| `model_performance_roc_pr_analysis.py` | Model Performance & Curve Analysis | Random Forest, ROC/AUC |
| `raisin_classification_logistic.py` | Raisin Type Classification | Logistic Regression |

## 💡 Note
The inline comments in the scripts are in Turkish as they reflect my local learning notes during the laboratory process. The main objective was to use AI as a development tool to produce optimized and high-accuracy results (reaching 1.00 accuracy in several models) in minimal time.
